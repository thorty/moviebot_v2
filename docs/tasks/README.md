# Task-Lerndoku (Junior Guide)

Dieses Verzeichnis enthält pro abgeschlossenem Task eine kurze, praxisnahe Lerndoku.

## Ziel
- Umsetzung Schritt für Schritt nachvollziehbar machen
- Nach jedem Task erklären: Was wurde getan, warum, wie testen
- Onboarding für Junior Devs erleichtern

## Reihenfolge
- `task-01.md`
- `task-02.md`
- `task-03.md`
- ...

## Verbindliche Regel
Ein Task ist erst abgeschlossen, wenn:
1. der technische Validierungs-Gate bestanden ist und
2. die passende Task-Doku (`task-XX.md`) vollständig ausgefüllt ist.

## Inhalte je Task-Doku
- Kurzüberblick
- Erklärung für Junior Dev
- Manuelle Schritte
- Testanleitung (inkl. erwartetes Ergebnis)
- Troubleshooting
